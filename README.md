# LOWKEYVANDALS

A quiet photographer discovery index.

## V1

The first release establishes the interface and deployment foundation for a daily discovery feed focused on street, urban, candid, documentary, film, nightlife, editorial and subculture photographers.

## Design

- Black text on white
- High legibility
- Generous whitespace
- 16–18px minimum reading text
- Thin rules
- Photography provides the visual colour

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm start
```
